Atlas privacy policy

Last updated November 23, 2026.

Atlas is a private personal assistant used only by its owner, Ryan Bourque. It is not available to anyone else.

What data Atlas accesses

With the owner's permission through Google sign-in, Atlas can read calendar events and calendars, and create, update or delete events. If Gmail access is granted, Atlas can read messages and create drafts, and can send or delete mail only after the owner approves each action.

How the data is used

Data is used only to answer the owner's own requests, such as summarizing his schedule or adding an event he asked for. It is not sold, shared with third parties, or used for advertising.

Where the data is stored

Access tokens are stored on the owner's own computer. Data is processed to answer requests and is not kept beyond what the owner's assistant needs to do that.

Google API Services User Data Policy

Atlas's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
